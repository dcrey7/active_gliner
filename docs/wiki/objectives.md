# Active GLiNER paper - objectives and reporting

Design: `docs/research/2026-09-25-1113-full-merge-design.md` (final, Codex round 19). Base rules: `docs/research/2026-09-25-1040-paper-direction-decision.md`.

## 0. The questions the paper answers

| # | Plain question | Role |
|---|---|---|
| Q1 | Does picking GLiNER's unsure examples beat random picks, with LLM labels and with ground truth, on 4 tasks? | primary |
| Q2 | Are the LLM's wrong labels on the same sentences where GLiNER is unsure or wrong? | secondary |
| Q3 | Do different LLMs fail on the same sentences? | secondary |
| Q4 | Does the larger model in a family label better? | secondary |
| Q5 | Does a better teacher give a better student? | secondary |
| Q6 | Can the small student match or beat its teacher? | secondary |
| Q7 | What does each option cost, and how fast is it? | descriptive |

## 2. Reporting to Abhishek

When: at the end of every objective, at every failure that blocks progress, and at least once a day while runs are going.

Where: a chat message in the fixed format below, plus a dated file in `docs/updates/`.

Fixed format:

```
Objective:   O# name - done / blocked / in progress
Result:      what now exists, with the numbers
Failed:      what went wrong, with the real error
Changed:     files and paths
Next:        the next step, and what I need from you (if anything)
```

Rules:

+ Real numbers only, from logs or commands run in that session.
+ A failed test is reported as failed, with its output.
+ Time and date come from the shell, never guessed.
+ Every design change goes to Codex for review before it is applied, and the report says so.

## 3. Community rules to follow

Source: guidelines research of 25 Sep 2026 (ARR Responsible NLP checklist, ACL AI policy, arXiv policies, NeurIPS checklist, Dror 2018, deep-significance, Lüth 2023, Zhang 2022). O10 is not done until every box is ticked or marked N/A with a reason.

Paper content (ARR checklist):

- [ ] A1 Limitations section after the conclusion, before references.
- [ ] A2 Risks: misuse, environmental impact, bias, privacy.
- [ ] B1 Cite every artifact with version and URL (6 datasets, GLiNER2.5, Gemma 4, Qwen 3.8).
- [ ] B2 Licence of each artifact stated. B3 our use matches its intended use.
- [ ] B4 PII and offensive content: what we did.
- [ ] B5 Domain, language, coverage of each dataset. B6 counts per split (measured at load).
- [ ] C1 Parameter counts, GPU hours (including teacher labelling and failed runs), hardware.
- [ ] C2 Hyperparameter search and final values (LoRA rank, alpha, targets, lr, steps, thresholds).
- [ ] C3 Error bars or intervals; say for each number whether it is one run or an aggregate.
- [ ] C4 Package versions and settings (gliner2, peft, transformers, torch, llama.cpp build).
- [ ] D1-D5 N/A: no human annotators; ground truth comes from published datasets. Say so.
- [ ] E1 AI assistants: Codex and Claude wrote code and helped draft text; state what was checked by hand.

AI and authorship:

- [ ] Acknowledgements disclose AI help for code and writing. No AI as author.
- [ ] Every citation checked by hand to exist (ACL 2026 desk-rejected papers for invented references).
- [ ] Teachers fully described: checkpoint, quantisation, prompt, decoding settings.

Reproducibility:

- [ ] Seeds listed; each seed varies pool tie-breaks, data order and LoRA initialisation.
- [ ] Code, configs, selected-example ids and teacher outputs released with instructions.
- [ ] Energy estimate: GPU hours x about 350 W, converted with the French grid intensity; tool named.

Statistics and active learning:

- [ ] Paired bootstrap or permutation tests on F1 (no t-test on raw F1 alone).
- [ ] ASO (deep-significance) over seeds with epsilon_min reported (design change, Codex round 13).
- [ ] Multiple-comparison correction (Holm, already in the design).
- [ ] Random baseline always present; zero-shot and full-pool LLM baselines present.
- [ ] Two budgets per task; validation set frozen before any tuning.
- [ ] Cost also in annotated tokens and entities, not only sentences (design change, Codex round 13).
- [ ] Discuss successor-model mismatch: selection by the zero-shot model, training of the LoRA student.

Documentation:

- [ ] Data statement for released LLM labels: labelled as LLM-generated, teacher, prompt, measured noise rate.
- [ ] HF model cards for adapters: data, licence, limitations, intended use.
- [ ] Derived labels keep source licence terms (CleanCoNLL ids + offsets only; CrossRE and Hallmarks GPL-3.0).

arXiv:

- [ ] Endorser secured (O11).
- [ ] LaTeX source upload with `.bbl`; figures PDF/PNG/JPG; ACL template with `\usepackage[preprint]{acl}`.
- [ ] Written fully in English; framed as an empirical paper.
- [ ] arXiv licence CC BY 4.0.
